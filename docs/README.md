# Crowd — Documentation

This directory holds project documentation that isn't tied to a specific code package. Most contributors won't read every file here; the layout below is for orienting when you need something specific.

## Layout

- `infra/` — deployment and infrastructure documentation (Fly, Neon, Vercel, EAS setup notes)
- `feats/` — feature specs and design notes, often pre-implementation
- `bugs/` — bug post-mortems and diagnostic write-ups
- `archive/` — historical snapshots, not current state

## Where to look first

The active backlog and decisions log live in `docs/followups.md`. Read that first — it's the running record of what's deferred, what's been settled, and what working principles have emerged from the work.

The design system is documented in `docs/design-system.md`.
